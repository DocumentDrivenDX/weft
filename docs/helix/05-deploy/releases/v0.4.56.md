# Weft 0.4.56

## Release scope

This record describes the scoped `umf-weft==0.4.56` release. The Python import
remains `weft`; the release is based on the reviewed 0.4.56 producer source.

The scoped compiler change selects a Weft module envelope at version 0.2 for
matching non-null literal defaults. Ordinary UMF AST declarations remain at
0.1; omission is not filled into user input, and native-only temporal behavior
is unchanged. CONTRACT-003 carries Boolean, string, integer, exact-decimal,
UUID, and 128-bit bit-string defaults. Logical date and timestamp defaults
remain excluded, and existing native capacity checks remain in force. These
statements record implementation scope, not a broader adapter claim.

## Qualification scope

The release profile is local and uses no Actions workflow. Its exact artifact
scope is the three `cp39-abi3` wheels for Linux x86_64, Linux ARM64, and macOS
ARM64, together with the bounded source, build, qualification, and asset
records described in the [local operator runbook](../local-release-runbook-0.4.56.md).
Local provenance is unsigned and does not claim a hosted workflow identity.

The bounded Linux source/package guards have an accepted result for the P56
producer under Linux x86_64, Python 3.11.17, and Bun 1.4.3. This result does
not establish Python 3.12 coverage. The exact x86_64 Linux native campaign
retained 19 raw scenario dispatches and an original `FAIL_OR_UNKNOWN` operator
receipt. A separate reviewer-accepted pure predicate reanalysis found all 14
case predicates satisfied while preserving that original failure. This is
analysis of the retained run, not a rerun or a new runtime observation.

The x86_64 and ARM64 Linux wheels have accepted static artifact evidence. The
macOS ARM64 wheel has an accepted build/static-audit chain only; the original
build failure and separate static-only audit remain distinct records. This
evidence does not establish macOS installation or runtime behavior. The
reviewed Table012 inherited-boundary receipt and reviewed full Truss011 receipt
are retained under their original profiles. The same Truss011 run supports
both browser and WASM obligations, with exactly ten selected-software witnesses
rehash-verified outside the evidence ZIP. The macOS compiler was used only to
build the wheel; no macOS compiler conformance, native runtime, browser, or
installed-wheel tests ran.

Support statements apply only to the listed versions, platforms, and evidence.
Artifact availability and exact published digests are established by the
versioned release assets and public-index readbacks.
