# Weft v0.4.36

This candidate adds explicit Truss backend0.4.39 support for decimal(12,2), needed
by the unmodified Northwind Product.unitPrice/Order.freight/OrderLine.discount
fields. Earlier backend0.4.38 requests retain their previous facet refusals.

The additional domain uses existing exact decimal cells and PostgreSQL numeric
comparisons. Original text such as9999999999.9900 is retained; nonrepresentable
values refuse without rounding. Scalar/item projections, equality, relationship
keys and an explicitly selected typed page path share the declared domain.
Native accepted model/catalog/runtime correspondence remains required.

The new backend also uses an original stable Record or Field ID when its authored
name is absent. An authored name takes precedence, punctuation requires ordinary
SQL quoting, and ambiguous matches refuse. Earlier backend selections remain
name-only. Original accepted module and binding bytes are retained.

Existing protected String/I64 candidate profiles, native permissions and frozen
browser cohorts are unchanged. The compiler release does not complete B-008 or
promote native acceptance cases. All132 original requirements and existing case
acceptances remain in force.
