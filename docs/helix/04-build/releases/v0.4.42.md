# Weft Python 0.4.42

This maintenance update starts from published 0.4.41 and fixes large Truss
catalog compilation. The explicit Truss backend 0.4.41 / target 0.5 / compile0.2.7
profile admits one million JSON values per model and binding within the existing
four-MiB byte bound. Generic readers and other registrations retain their
100,000-value bound. Duplicate JSON members, excessive depth, source-pin changes
and byte/value overflow continue to refuse compilation.

Prepared catalogs build an immutable coordinate index once instead of repeatedly
scanning all original elements for each Field or Record lookup. Original model
bytes, definition order, unknown content and emitted artifacts remain unchanged.
The [genuine 1,000-type fixture](../../../../tests/truss-catalog-capacity/README.md)
records the reproduced refusal, successful compilation and exact-artifact
comparison. Every published wheel runs its positive and negative controls.

The compiler remains pure and grants no native database authority. This update
does not release the separate feature work on main. Python ABI3 platform support,
backend versions and existing candidate qualification retain the scope of 0.4.41.
