# Weft v0.4.31

Extends Truss backend 0.4.36 compatibility to native runtimes 0.66 and 0.67;
native0.65 retains backend0.4.35. Query, page and mutation-selection compilation preserve original binding
release IDs and digests; unqualified releases and backend mismatches refuse.
No client key encoder is added. Truss 0.67 derives keys in PostgreSQL.

Includes previously unreleased owned-runtime backend and current lineage work
already on main. Execution and authority remain host responsibilities. Release
CI produces platform wheels with exact source and backend pins.
