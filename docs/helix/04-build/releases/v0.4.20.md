# Weft v0.4.20 — optional binary equality

Truss backend0.4.25 extends byte equality to singular absent-allowed binary
fields. A distinct compare.binary.optionalEqual capability is required if
either operand is optional; retained backend0.4.24 refuses it before mapping.
Original type graph availability and absent/null projection distinctions remain.
Strict PostgreSQL decode propagates absent/null to SQL UNKNOWN/nonmatch;
empty byte values remain real values. Wire0.2.5 is unchanged.

Basic public UMF07/08 filters, INNER joins, pages, reads and read-only workflows
pass with matching Truss native55/SDK18. This adds no null parameter,
timestamp comparison, ordering, grouping or relationship-key domain.
