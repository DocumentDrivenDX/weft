# Weft v0.4.5

Matching Python compiler wheels for Truss v0.0.3 / native runtime0.40-candidate.
Truss backend0.4.10 admits the new typed-business-key runtime and retains the
existing exact numeric query behavior. Older backend versions remain available.
This is runtime compatibility, not new SQL syntax or typed query pagination.

Release workflow builds/smokes Python>=3.9 ABI3 wheels for Linuxx86_64/arm64,
macOSx86_64/arm64 and Windowsx86_64, then publishes SHA256SUMS and source/build
pins. Hosts own transactions, execution and authorization. Truss separately
checks native workflows against the exact published wheels.
