# Weft 0.4.48

**Status:** draft; local macOS ARM functional qualification and final wheel
hashes are pending. This draft does not claim release qualification has passed.

## Release scope

- Version: 0.4.48
- Release date and rollout window: pending qualification and release scheduling
- Release owner: pending
- Planned channel: GitHub release with platform wheels

## Audience and highlights

Python compiler consumers gain the declared-table lifecycle and seed APIs,
bounded batch operations, and fixed typed-query operations under their existing
compiler and host contracts. Prepared modules reuse admitted schema metadata
and indexes. This does not widen the supported UMF feature set or grant host
authorization.

## Required actions and compatibility

Models using UMF source formats below 0.10.0 must be upgraded before they can be
compiled by this release. Authored source meaning remains explicit, and host
authorization remains host-owned. Consumers should stay on their current
release until the exact-wheel qualification report is complete.

No additional operator action is known for users already supplying supported
0.10.0 source.

## Qualification and known limits

The planned release gate performs functional qualification once against the
exact installed macOS ARM wheel. Other hosted platforms build/import their wheel
and verify archive metadata, notices, and native-module identity only. No native
Spark or Databricks execution qualification, full-suite qualification, or
cross-platform functional qualification is claimed here.
