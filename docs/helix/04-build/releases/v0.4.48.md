# Weft 0.4.48

The Python compiler now prepares one shared UMF 0.10 schema and indexed metadata for declared native tables, writes, seeds and typed queries. Eligible independent insert batches lower to one mutation statement. Batch eligibility computes dependency components once; allowed-value checks and query/seed lookups reuse prepared indexes. Calls do not copy, hash or re-admit the whole schema.

Typed-query fixes cover nullable unrefined NUMERIC results, native primary-key GROUP BY behavior under identity column mappings, PostgreSQL LEFT, and binary64 result transport. Renamed column projections still require complete GROUP BY expressions. Producer build labels are descriptive provenance; the versioned interface, schema and source semantics remain checked.

Use current UMF 0.10.0 source with UMF SDK 0.5.2 and host 0.1.0.dev4. Source formats below 0.10 and old installation upgrade paths are unsupported; independently versioned backend/codec IDs remain distinct.

Functional qualification is local macOS ARM64 with PostgreSQL 18.6. All 80 actual embedder queries passed 483 native comparisons; their prepared programs remain byte-identical on the final indexed compiler. Seven sample methods/eight operations passed 15 checks. The final installed wheel passed four batch cases/58 assertions, including 1,000 inserts in one mutation statement. Every lease was returned. All recorded maintained failures were repaired through focused checks: 24 core, 41 runtime, 22 PostgreSQL selectors and the paths-keys CLI; the Databricks compiler follow-up passed 123 tests. The historical B-001 spike is outside maintained release qualification; the whole workspace campaign was not repeated or claimed green.

Other platform jobs build/import packages and check archive metadata, RECORD, notices and native identity only. No cross-platform functional qualification, live Spark/Databricks execution, time-only query codec, or complete application/external-reference integration is claimed. The exact local artifact and detailed scope are in [local-macos-0.4.48.json](local-macos-0.4.48.json).
