# Weft v0.4.24

Adds explicitly selected UMF RFC3339 exact-instant equality through compile/IR/
backend0.2.6 and the Truss PostgreSQL18.6 backend0.4.29/native59. Timestamp query
operands retain original text and compare without fractional precision loss;
filters, joins and pages support required and absent-allowed fields. Binary and
previous query profiles remain separately versioned. Ashlar timestamp admission,
timestamp ordering/grouping and temporal keys remain unavailable.

Basic Rust and public Truss PostgreSQL workflows verify this tranche. Matching
wheels are released by the existing GitHub workflow; this source note is not a
publication claim.
