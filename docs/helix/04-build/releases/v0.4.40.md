# Weft0.4.40 combined compiler release

Combines published0.4.39 Date source and its reviewed browser string-import gate
with the original typed SDK read/action/bulk/search and authored-Key page APIs.
The declared standard Python feature set includes the SDK entrypoints. Rust and
Python versions use the existing stable0.4.40 spelling; historical smoke parsing
and all five-platform release gates remain intact.

Underlying Truss Date queries retain backend0.4.41, compile0.2.7 and original
truss-postgresql-logical-query/1.1 ABI. Old backend0.4.39/ABI1.0 programs remain
separate. SDK selected temporal semantics remain HELD. The Truss default is not
changed by this compiler source or by a compiler smoke result.

Original page programs preserve complete native artifacts and Key metadata.
Ashlar page language additions use distinct candidate backend versions rather
than modifying historical registrations. Native context, publication, current
policy, Key integrity and final release are engine duties. These source/API
additions do not promote complete SDK, managed action or protected Truss action/
manifest qualification. Publication requires the unchanged complete CI and all
five platform wheel gates, with exact release pins and SHA256SUMS.
