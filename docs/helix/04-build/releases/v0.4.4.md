# Weft v0.4.4

Matching compiler wheels for Truss v0.0.2 / native runtime0.39-candidate.
The PG18 Truss backend0.4.9 accepts original UMF signed64 integer and
precision18/scale4 decimal facets. SQL lowering and parameters preserve exact
values without float conversion or typmod rounding. Older backend profiles
retain their existing behavior.

The release workflow builds and smoke-tests Python>=3.9 ABI3 wheels for Linux
x86_64/arm64, macOS x86_64/arm64 and Windows x86_64. SHA256SUMS and
release-pins.json identify uploaded assets and exact source/build pins.

This release supplies the compiler; hosts own PostgreSQL connections,
transactions, execution and authorization. No broader numeric facet combination,
managed-database or protected-engine claim follows.
