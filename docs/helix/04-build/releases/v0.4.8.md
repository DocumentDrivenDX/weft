# Weft v0.4.8

Adds the Truss PostgreSQL18.6 backend0.4.13/runtime0.43 pairing for the scalar array/map Python release. Earlier exact backend/runtime pairings remain supported. This release preserves scalar query behavior; catalogs containing containers are explicitly refused by Truss until projection support lands.

Five ABI3 wheels target Linuxx86_64/arm64, macOSarm64/x86_64 and Windowsx86_64. Rust1.90.0/maturin1.9.6 and exact wheel digests are recorded in release-pins.json and SHA256SUMS. Local matching-wheel basic Truss workflows pass.
