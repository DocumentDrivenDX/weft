# Weft v0.4.19 — Truss binary equality

The Truss runtime backend0.4.24 admits required singular binary byte equality
with literals, explicitly typed named parameters and INNER-join fields.
Compile/IR/backend0.2.5 carry binary types separately from existing atomic
families. Existing versioned schemas and backends retain their prior profiles.
Canonical bounded base64 is validated before decoded PostgreSQL byte comparison;
projection retains original tokens. Truss native0.54 is the matching runtime.

Basic installed Python UMF07/08 workflows pass for writes, reads, equality,
empty binary bytes, no-match results, malformed/wrong-family refusals and
read-only queries. Core/PostgreSQL build and workspace test-target compilation
pass; module boundaries cover11 packages. Astra Ultra reviewed the source.
Timestamp comparison, binary ordering/grouping and binary relationship keys
remain outside this release. Publication uses the existing wheel workflows.
