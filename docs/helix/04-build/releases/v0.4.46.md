# Weft 0.4.46

Truss raw reads and related-key reads now consume current UMF 0.10.0 source,
including original Record/Field IDs when authored names are absent. Authored
names retain precedence. Compile-request and logical-plan 0.2.7 schemas now
admit the current core version. Date, binary and export fixtures use current
source documents.

The raw-read profile retains object-valued `umf.ddd` Record metadata and
`hohfeld.view` Record/Field metadata without interpreting those payloads.
Unknown selected extensions, malformed payloads and unresolved semantic-type
references still refuse. Original source bytes and model pins are preserved.
This change adds no host authorization or native execution authority.

PostgreSQL raw reads, related reads, search and raw-bulk programs now include
compiler-owned `dbapiSql` and `dbapiParameterOrder`. Token spans preserve original
SQL bytes, quoted content, Unicode and literal percent/dollar characters;
bindings follow placeholder occurrence order, including repeats. Related-read
transport is generated after composing source and target parameter inventories.
Both representations are included in the program's structural digest. Hosts
must retain these compiler fields when checking that digest rather than replace
them with a host SQL rewrite. Truss's registered-engine compiler APIs retain their
existing transport.

The recorded DBAPI subset passes 183 PostgreSQL library tests and 187 generated
client/native PostgreSQL 18.6 assertions with Psycopg 2/3 and SQLAlchemy sync/async
transports. See [the exact source and wheel evidence](../evidence/praxis-dbapi/README.md).
Those native assertions use a bounded fixture executor, not UMF's legacy
`reviewed.py` production executor. That consumer needs a compatible successor
before admitting these newly sealed programs. This profile does not qualify
table admission, mutations, DDL, policy/grant generation or complete Praxis
lifecycle integration.

The candidate Rust workspace passed locally with the candidate Truss and Ashlar
registrations. Focused qualified raw-read and related-key checks also passed.
Publication requires the frozen source's conformance workflow and every exact
platform wheel's existing packaging, compiler, capacity and ABI smoke checks.
Actual installed Truss native qualification and its full stress matrix remain
Truss release gates; this compiler release does not claim those gates passed.
