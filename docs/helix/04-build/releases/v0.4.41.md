# Weft 0.4.41 SDK compiler release

Stable Python compiler distribution for the original non-temporal SDK engine
read/page custody APIs, explicit bounded Truss cursor export, and PostgreSQL
null-safe distinctness predicates. Python and Rust distribution versions are
both canonical `0.4.41`; the separate explicit backend versions remain unchanged.

The standard wheel retains every previous compiler feature and publication
check. Each of the five exact platform wheels must now additionally pass twenty-two
SDK compiler controls, including both original Ashlar read/page profiles, original program/context refusal and equal-carrier
null-safe predicates. Publication validates a closed report inventory against the
same wheel/native-module/shim hashes, source commit and version as the previous
current-query smoke. All previous packaging, Date, Decimal12, query ABI, native70,
refinement, Databricks and promotion gates remain mandatory.

Cursor export uses backend `0.4.42` / `truss-runtime-pg18.6-export/0.1`, retains
the complete original backend `0.4.41` page program, and declares host-owned
fixed-cursor/current-authority/cleanup obligations. It retains the bounded source
profile; scalable native source wiring is not part of this release. Compilation
never opens a transaction or grants native authority.

SDK temporal qualification remains **HELD**. Underlying ordinary Date compiler
support remains separately qualified; this release does not change Truss defaults,
activate protected actions, broaden managed mutations/search, or close full SDK
acceptance. Hosts must qualify the exact released wheel before adoption. Existing
`v0.4.40` wheels and historical tags remain available for rollback.

Source behavior and real PostgreSQL/Chromium replay precede this release in
[raw-read distinctness evidence](../evidence/raw-read-distinctness-20261016/README.md)
and [cursor export evidence](../evidence/typed-sdk-export-20261016/).
Public release success and exact artifact digests are recorded only after all
required CI and five-platform release gates complete.
