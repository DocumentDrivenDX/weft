# Weft 0.4.45

Current-query and presence preparations now admit coherent UMF 0.10.0 source
using its actual schema, exact source bytes and model pins. Their typed packets
and conditional lowerers preserve that version; mixed source formats and
unresolved external semantic references refuse. Host authorization and native
execution obligations are unchanged.

Validation: 387 compiler core tests pass locally. Each published wheel must pass
the existing native smoke suite plus an actual UMF 0.10 current-query preparation
and PostgreSQL ABI2 lowering. This release also includes the repository's
MIT OR Apache-2.0 license update.
