# Weft 0.4.54

This release candidate integrates the selected Unity current aggregate compiler
work with the existing G02 typed-expression compiler. UMF retains source meaning
and inert migration plans; Weft prepares qualified SQL and recipes; the host owns
execution, transaction boundaries and authority.

The compiler source is **32b5ad36fe28cebb4073b3a152f086c47a8d0fa2** (S). The release tag
will target the normal metadata merge (M). The generated
`release-pins-0.4.54.json` binds both commits; no document embeds its own commit
hash. Publication and public-byte readback remain pending at this checkpoint.

## Changes and retained evidence

- Integrates exact SUM/AVG aggregate lowering, checked predicates and selected
  current Unity read routes, including empty-membership Boolean semantics.
  The retained aggregate compiler and installed Python/Chromium evidence stays
  qualified by its recorded source, feature set, backend versions and vectors.
- Retains the separate PostgreSQL 18.6 source qualification from
  [PR 30](https://github.com/DocumentDrivenDX/weft/pull/30): 50 native SQL cases
  and 56 selected Python/Chromium compiler comparisons. That source evidence
  does not establish a production executor or migration authority.
- Packages Linux x86_64, Linux aarch64 and macOS ARM64 wheels with exact archive,
  embedded native-module, metadata, ABI-tag and notice checks.
- Builds the hosted macOS WASM comparator in release mode: 10,047,275 bytes
  within the unchanged 20 MiB cap.

## Release artifacts and scope

All three wheels were built at S. Both Linux jobs in
[run 40258052788](https://github.com/DocumentDrivenDX/weft/actions/runs/40258052788)
passed; its publication job was skipped. The actual `macos-14` ARM64 producer in
[run 40258058816](https://github.com/DocumentDrivenDX/weft/actions/runs/40258058816)
passed preflight, wheel installation, Rust comparison and real Chromium parity.
The asset policy records every wheel and embedded native-module hash.

The nine macOS comparisons are **refusal-response parity** for older backend
profiles: PostgreSQL requests return `WFT-BACKEND-MISSING`, and Databricks
requests return `WFT-BACKEND-VERSION`. Installed Python and Chromium WASM match
the exact Rust response bytes in every case. These checks do not qualify
positive macOS query compilation, native PostgreSQL execution, a production
executor, durable storage, authorization, generated clients, Psycopg2,
SQLAlchemy or managed database deployments. Linux artifact producers establish
packaging identity only. Separate retained compiler/native evidence is not
expanded by these packaging results.

The dedicated publisher must validate the successful producer identities,
unchanged compiler/build inputs between S and M, the exact three-wheel asset
set, draft tag and remote byte readback before promotion. Old failed macOS
artifacts and local receipts are ineligible. No PyPI publication is claimed.
