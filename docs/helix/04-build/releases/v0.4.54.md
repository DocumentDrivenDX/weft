# Weft 0.4.54 release preparation

This document reserves a source-reviewed release-preparation path for version
0.4.54. The tag and release do not exist. Source commit **S**, metadata commit
**M**, the Linux artifact run, the hosted macOS ARM64 run, and all three wheel
hashes remain unassigned until their gated builds and reviews complete.

The release path retains the existing Linux x86_64 and aarch64 artifact-only
matrix, and adds a read-only hosted macOS ARM64 build on `macos-14`. The macOS
producer must identify its actual runner architecture, SDK, Python, Rust,
Maturin and compiler inputs; build the versioned wheel at S; install and check
that exact wheel; and compare nine selected public compiler fixtures across the
Rust comparator, installed Python wheel and actual Chromium WASM. That selected
compiler scope is not native database execution or broad platform qualification.
GitHub's current hosted-runner reference maps the standard `macos-14` label to
ARM64 (M1); repository runner availability, actual image, and observed
architecture still require evidence from the hosted producer
([runner reference](https://docs.github.com/en/actions/reference/runners/github-hosted-runners)).

Promotion is held until both Linux jobs and the hosted macOS producer pass at
S, their successful run identities and exact wheel/native-module hashes agree,
and a dedicated publisher at M validates the draft tag and source/build-input
identity. The publisher refuses the legacy local macOS receipt, any extra or
missing wheel, wrong or duplicate artifact, changed bytes, absent selected
checks, wrong source/run identity, or a non-draft release. It reconciles the
exact candidate asset set and reads back the remote bytes before promotion.

No tag, draft release, artifact workflow dispatch, credentialed action, upload,
or publication was created by this source preparation. No native PostgreSQL,
production execution, or broader support claim is made.
