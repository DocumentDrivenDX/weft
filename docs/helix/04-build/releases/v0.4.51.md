# Weft 0.4.51

## Release scope

Python wheel candidate for Truss0.0.48 embedders, intended for GitHub release
assets; the repository maintainer owns publication. The current compiler/build
source freeze is `557153731e9f5d0583193a1189a07c6ed485d3d3` (source F), selected
from the public0.4.49 lineage. Full selected-source workspace tests at
`56d5507c6b0169574277661dd85d8c5feb22e6a7` passed with 1,046 default-profile
tests and 1,047 qualified-profile tests across 62 summaries per run. No
protected compiler/build inputs differ from source F.

The Mac ARM64 source-F wheel and native module were rebuilt and independently
checked. The new module passed 51 exact-feature runtime library tests, 33 native
entity-selection cases and 5 native facts cases. No new source-F Chromium run is
claimed here. Linux packaging and independent archive verification passed for x86_64 and
aarch64 from source F; packaging alone is claimed for both Linux targets. No
source-F Linux Truss host or database execution is claimed. Hosted final conformance run 39822650250 completed
successfully with all source jobs and steps passing. Its testability/workflow identities and limited host-evidence scope are
recorded separately. Source-F Truss host gates passed on local macOS
ARM64/PostgreSQL18.6 for 80 migration cases, 62 independent archive cases, six
cohort tests, 14 policy executions over 10 distinct controls and the
1,000-object/1,000-edge workload. Four policy executions repeat imported query tests. Publication and
release/tag gates remain separate.

## Audience and channels

Truss and Arras maintainers receive the compiler wheels, SHA256SUMS and exact
release pins through the GitHub release. Applications consume the matching Truss
host; the compiler itself does not connect to a database.

## Highlights

- Explicit entity descriptors preserve ordered Fields, related projections and
  selected native facts; eight facts are available through the declared interface.
- Truss query ABI1.2 supports bounded indexed sources and eligible key pages,
  with complete bounded fallback for other admitted queries.
- Original arras.view0.1.0 Record/Field metadata is admitted only under its exact
  owning-document vocabulary declaration. Unsupported selected versions refuse.

## Changes and fixes

Compile/IR0.2.8 and backend43/44 are explicit registrations; published0.2.7 behavior
remains unchanged. Typed resolution diagnostics preserve failure classification.
The historical 31 entity compilation cases remain, with two additional Arras
positive/refusal cases. Separate facts compilation retains five parity cases.
Opaque Arras metadata does not grant it security or storage semantics.

Publisher receipts bind actual build checkouts, wheel/module hashes and frozen
compiler/build/contract inputs. A mixed-source platform cohort refuses publication.

## Breaking changes and required actions

Install the checksum-verified platform Weft0.4.51 wheel with the matching
Truss0.0.48 host before selecting the new ABI. Keep exact native module and host
pins aligned; same-version candidate wheels can contain different compiler bytes.
Applications using the unchanged published ABI need no query-language rewrite.

## Migration or rollback guidance

Weft changes no database schema. Truss owns explicit offline database migration
and its latest-only runtime policy. Quiesce writers, retain backups and use the
Truss migration guide before resuming application work. Hold on compiler/host
mismatch or failed admission; restoring an old application package is not a
rollback for an upgraded database.
