# Weft 0.4.51

## Release scope

Weft 0.4.51 was published on 2026-10-22 at the [GitHub release page](https://github.com/DocumentDrivenDX/weft/releases/tag/v0.4.51). The tag source is `d4b0b98507ae15bd98180a2ea2030ea92ce11d96`; compiler/build source freeze F is `557153731e9f5d0583193a1189a07c6ed485d3d3`. The full selected workspace passed 1,046 candidate-profile and 1,047 qualified-profile tests across 62 summaries per run. Protected compiler/build inputs match F.

The public release contains three wheels (macOS ARM64, Linux x86_64 and Linux aarch64), three packaging reports, the macOS qualification report, SHA256SUMS and release pins. All nine assets passed independent verification. The public [SHA256SUMS manifest](https://github.com/DocumentDrivenDX/weft/releases/download/v0.4.51/SHA256SUMS) has SHA-256 `62c9d8082eb2f446446d7b94ff7ef7f48769e3cd836e5641c2951069302a6c75`. A clean install of the published macOS wheel passed packaging verification, all 33 entity cases and all 5 facts cases. The selected native module also passed 51 exact-feature runtime library tests.

Source-F Linux packaging and independent archive checks passed for both Linux targets; those checks do not qualify Linux database or Truss host execution. Historical Linux parity evidence is identified by its own source and profile in the [evidence packet](../evidence/release051-source557-20261022/README.md). The source-F Truss host gates passed locally on macOS ARM64 with PostgreSQL 18.6: 80 migration cases, 62 independent archive cases, six cohort tests, 14 policy executions across 10 distinct controls, and a 1,000-object/1,000-edge workload. Four policy executions repeat imported query tests. No Linux host execution is claimed.

## Audience and channels

Truss and Arras maintainers can obtain the compiler wheels, SHA256SUMS and exact
release pins from the [public GitHub release](https://github.com/DocumentDrivenDX/weft/releases/tag/v0.4.51). Applications consume a matching host; the compiler itself does not connect to a database.

## Highlights

- Explicit entity descriptors preserve ordered Fields, related projections and
  selected native facts; eight facts are available through the declared interface.
- Truss query ABI1.2 supports bounded indexed sources and eligible key pages,
  with complete bounded fallback for other admitted queries.
- Original arras.view0.1.0 Record/Field metadata is admitted only under its exact
  owning-document vocabulary declaration. Unsupported selected versions refuse.

## Changes and fixes

Compile/IR0.2.8 and backend43/44 are explicit registrations; published0.2.7 behavior
remains unchanged. Typed resolution diagnostics preserve failure classification.
The historical 31 entity compilation cases remain, with two additional Arras
positive/refusal cases. Separate facts compilation retains five parity cases.
Opaque Arras metadata does not grant it security or storage semantics.

Publisher receipts bind actual build checkouts, wheel/module hashes and frozen
compiler/build/contract inputs. A mixed-source platform cohort refuses publication.

## Breaking changes and required actions

Install the checksum-verified platform wheel and use a host build whose native
module and release pins match it. Same-version candidate wheels can contain
different compiler bytes, so verify the exact artifact pair before selecting the
new ABI. Applications using the unchanged published ABI need no query-language
rewrite.

## Migration or rollback guidance

Weft changes no database schema. Truss owns explicit offline database migration
and its latest-only runtime policy. Quiesce writers, retain backups and use the
Truss migration guide before resuming application work. Hold on compiler/host
mismatch or failed admission; restoring an old application package is not a
rollback for an upgraded database.

cohort/asset-cache tests, 14 policy executions across 10 distinct controls, and
the 1,000-object/1,000-edge workload. Four policy executions repeat imported
query tests; they are not additional distinct controls. The successful hosted fresh-host receipt is limited to 2,181 retired UMF 0.7
refusals and stated parity controls; it does not qualify current Truss compilation
or database execution. The Truss host receipts are local macOS/PostgreSQL evidence only. The exact
public release verification passed all nine assets, and a separate clean public
Mac install passed packaging plus 33 entity and 5 facts cases. Linux runtime
qualification remains open; both Linux wheels have packaging evidence only.
Table-operation evidence records candidate SQL behavior and binding cases; it
does not qualify generated/runtime operation admission. Managed UC/Spark4.2,
protected migration and broad p95 targets are not qualified.
The selected release excludes main's separate managed candidates. Arras owns its
full adapter acceptance against the public dependency pair.
