# Weft v0.4.3

Python ABI3 wheels include the public Truss PostgreSQL 18 backend feature.
Distribution and `weft.__version__` are 0.4.3; Truss runtime backend is 0.4.8,
with compile/IR/backend interfaces 0.2.4 and entity-read 0.3.

Wheels are built and import-smoked on Linux x86_64/arm64, macOS x86_64/arm64
and Windows x86_64. Linux wheels use manylinux2014 repair. These are compiler
platform checks, not PostgreSQL execution claims. Truss v0.0.1 separately checks
its complete basic installed workflow on Linux x86_64 and macOS arm64.

SHA256SUMS covers the exact uploaded wheels. Source commit and selected runtime
are recorded in release-pins.json. GitHub provides the tagged source archives;
no independently verified Python source distribution is claimed here.
