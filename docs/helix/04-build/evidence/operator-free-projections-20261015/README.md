# Actual operator-free Weft projection producer corpus

The installed public Weft0.4.34 ARM wheel emits four actual retained-parent CQP
native packets for plain salary, WHERE FALSE salary, LIMIT0 salary and stored-token
projection. Each original request and packet is retained with byte hashes. The
original prepared request owns its source bytes; the child returns the same actual
parent, and repeat export preserves exact bytes. The actual installed extension
and shim are compared with the downloaded public wheel before execution.

Each packet has one exact original projection Field descriptor and no field query
route or operator. FALSE adds only its original Boolean operation with null
operator and no operands. The salary descriptor remains the original required
signed64 Integer; a read transform's String output must be derived from original
UMF read metadata, not a fabricated equality/query operator or domains[0]. The
stored token retains its original String Field identity. The retained requests
change only query SQL and parameters in the unchanged original source fixture.

This corpus is input to the separately versioned UMF read-projection child bridge.
It does not contain fabricated inspector responses, active read dispositions,
uniform effective-domain decisions, native results, caller/current authority or
protected release. WHERE FALSE/LIMIT0 are query constructs, not observations from
a database. No original132 backend case is promoted by these four producer tests.
